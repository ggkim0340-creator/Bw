SAVE_DATA 파일 업로드 또는 이어하기 코드 입력으로 원하는 값을 수정하세요.
세이브 데이터는 서버에 저장되지 않고 처리 즉시 삭제됩니다.

1. 세이브 불러오기 방식

📁
SAVE_DATA 파일을 드래그하거나 클릭해서 선택
보통 SAVE_DATA / SAVE_DATA.dat 형식입니다
⚠️ 이어하기 코드 + 인증번호는 계정 전체 접근 권한과 같습니다.
본인 계정의 코드만 입력하세요. 처리 후 코드/인증번호는 새로 발급되며 기존 코드는 무효화됩니다.

2. 재화 수정

보유한 모든 종류의 캣프루트를 9999개로 채웁니다

3. 고양이

전체 고양이를 보유 상태로 전환합니다
