# BC Save Editor (웹 버전)

`bcsfe` 라이브러리를 이용해 배틀캣츠(Battle Cats) 세이브 파일을 웹 브라우저에서 편집하는 도구입니다.
Flask 백엔드 + 정적 HTML 프론트엔드로 구성되어 있습니다.

## 구성

```
bc-save-editor/
├── app.py            # Flask 백엔드 (세이브 파일 파싱/수정 API)
├── requirements.txt
└── static/
    └── index.html     # 프론트엔드 (업로드/옵션 선택/다운로드) - 탭 구조 반응형 레이아웃
```

## 로컬에서 실행해보기

```bash
pip install -r requirements.txt
python app.py
```

그 다음 브라우저에서 `http://localhost:5000` 접속.

## 실제로 다른 사람들이 쓸 수 있게 배포하기

Claude는 실제 도메인에 배포/호스팅은 해줄 수 없어서, 아래 중 하나로 직접 올리면 됩니다. 전부 무료 플랜으로 시작 가능합니다.

### 1) Render (추천, 가장 쉬움)
1. GitHub에 이 폴더를 저장소로 올리기
2. https://render.com 가입 → "New Web Service" → 방금 만든 저장소 선택
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `gunicorn app:app`
5. 배포되면 `https://프로젝트이름.onrender.com` 같은 주소가 생김 (무료 플랜은 첫 접속 시 로딩이 좀 걸릴 수 있음)

### 2) Railway
1. GitHub 저장소 연결 → 자동으로 `requirements.txt` 인식
2. Start Command를 `gunicorn app:app`으로 설정
3. Settings에서 도메인 생성(Generate Domain)

### 3) PythonAnywhere
- Flask 앱 업로드용 튜토리얼이 잘 되어 있어서 무료 플랜으로도 개인용 사이트 하나 정도는 충분함

## 화면 구성 (반응형)

- 상단 고정 헤더 + 탭 네비게이션(불러오기 / 재화 / 고양이 / 도감·장비) 구조로 개편했습니다.
- 860px 이상(PC/태블릿 가로)에서는 좌측 세로 탭 + 우측 콘텐츠 2단 레이아웃, 그 이하(모바일)에서는 상단 가로 스크롤 탭 + 1단 레이아웃으로 자동 전환됩니다.
- 제출 버튼은 화면 하단에 고정(sticky)되어 모바일에서도 스크롤 없이 바로 누를 수 있습니다.

## 지원 기능

- 파일 업로드 방식 또는 **이어하기 코드 + 인증번호** 방식으로 세이브 불러오기
- 캣푸드 / XP / NP / 레어·플래티넘·레전드 티켓 수치 설정
- 보유 캣프루트 / 캣아이 / 인식표(탈렌트 오브) 전체 최대치(9999)로 채우기
- 전체 고양이 해금, 궁극진화(트루폼) · 4단 진화 일괄 적용, 특수능력(탈렌트) 전체 최대치, 레벨 일괄 설정
- 적 도감(에너미 가이드) 전체 해금, 장비(특능) 슬롯 전체 해금, 냥메달 전체 획득
- 이어하기 코드 방식은 수정 후 PONOS 서버에 재업로드하고 새 코드/인증번호를 발급해서 화면에 보여줍니다 (기존 코드는 자동으로 무효화됨)

### ⚠️ 새로 추가된 기능(도감·장비, 4단 진화, 탈렌트 등)에 대한 주의

이번에 추가된 기능 중 일부(적 도감, 장비 슬롯, 냥메달, 탈렌트, 캣아이/인식표 등)는 `bcsfe` 라이브러리 버전에 따라 내부 속성 이름이 조금씩 다를 수 있습니다.
`app.py`의 `apply_edits` 함수는 각 기능을 개별적으로 `try/except`로 감싸서, 특정 기능이 설치된 버전과 맞지 않으면 **그 기능만 조용히 건너뛰고** 나머지는 정상 처리하도록 만들어져 있습니다. 건너뛴 기능은 처리 완료 후 화면에 노란색 안내 박스로 표시됩니다.

배포 전에 로컬에서 실제 세이브 파일로 각 옵션을 한 번씩 테스트해보고, 만약 특정 기능이 계속 경고로 뜬다면 `pip show bcsfe`로 설치된 버전을 확인한 뒤 해당 버전의 실제 속성명에 맞춰 `app.py`의 해당 블록만 수정하면 됩니다.

## ⚠️ 이어하기 코드 기능 관련 중요 주의사항

이어하기 코드 + 인증번호는 **그 계정 전체에 대한 접근 권한**과 동일합니다. 파일을 직접 안 올려도 되니까 편하지만, 그만큼 위험도도 큽니다.

- 절대 본인 계정이 아닌 코드를 입력하거나, 다른 사람에게 "코드+인증번호 알려주면 대신 만져줄게" 같은 식으로 받지 마세요. 이건 계정을 통째로 넘겨받는 것과 동일합니다.
- 이 사이트를 다른 사람도 쓰게 공개할 경우, 사용자가 실수로 다른 사람 코드를 입력하거나 낚시(피싱)에 이용될 소지가 있다는 점을 감안해야 합니다. 공개 배포 시 이 기능에 대한 경고 문구(이미 UI에 넣어둠)를 절대 지우지 마세요.
- 처리 후 기존 코드는 서버에서 새 코드로 대체되어 무효화됩니다. 안내 없이 조용히 계정을 가져가는 구조가 아니라, 사용자가 그 결과를 눈으로 직접 확인하고 새 코드로 다시 기기 연동을 하는 흐름입니다.

## 동시 처리 제한 (대기열)

한 번에 최대 **30명**까지만 동시에 세이브를 처리하고, 그 이상 몰리면 자동으로 대기열에 들어갑니다.

- 요청이 오면 즉시 작업(job)이 등록되고, 화면에는 몇 번째로 대기 중인지 실시간으로 표시됩니다.
- 처리 중인 작업이 30개 밑으로 내려가면 대기열에서 순서대로 자동 처리됩니다.
- 완료된 결과는 서버 메모리에 10분간만 보관되고 이후 자동 삭제됩니다.
- 이 큐는 서버 프로세스 메모리에 저장되므로, Render를 재배포하거나 워커를 여러 개 띄우면 대기열이 초기화/분산될 수 있습니다. `gunicorn app:app` 기본 설정(워커 1개) 그대로 쓰는 걸 권장합니다.

## 주의사항

- 업로드된 세이브 파일은 서버 메모리에서만 처리되고 디스크에 저장하지 않습니다. 그래도 공개 배포 시에는 개인정보(계정 데이터) 처리이므로, 저장 로직을 추가하지 않도록 유지하세요.
- 편집 전 원본 SAVE_DATA는 항상 백업해두는 걸 권장한다는 안내를 프론트엔드에 넣어뒀습니다.
- bcsfe는 서드파티 오픈소스 라이브러리라 게임 업데이트 이후 세이브 구조가 바뀌면 깨질 수 있습니다. 그럴 땐 `pip install --upgrade bcsfe`로 최신 버전인지 확인하세요.
